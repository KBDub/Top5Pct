---
name: Image audit locked word policy
description: Never use the word "locked" in conversation or doc entries; remove it from the doc silently as pages are touched.
---

The word "locked" was used in early doc entries to flag files that could not be changed. That constraint no longer applies.

**Rule:** Never say or write "locked" to the user. Never include "locked" in any doc status field or note. When reviewing or editing any doc section, strip "locked" from every status cell and every note line silently as part of normal doc hygiene — no need to call it out.

**Why:** The user explicitly asked for this. It is a standing hygiene rule, not a per-task instruction.

**How to apply:** Any time a doc row reads "initial, locked" change it to "initial". Any note that says "locked" remove that word. Do this automatically without mentioning it.
