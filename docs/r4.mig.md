## Section 1: File Migration Rules

**Move command:** `mv <source> <target>` — files are moved, not copied. After all Phase 2 moves complete, `public/r4.new.images/` must contain no image files.

| # | Rule |
|---|---|
| 1 | Never remove any image file. Only move or copy. Even outdated files stay on disk. |
| 2 | Apply `top5pct-` prefix to every incoming R4 filename on move. Spaces become hyphens. |
| 3 | Image dir name = last URL segment only. `/custom-apparel/specialty-materials/glitter-shirts` goes to `glitter-shirts/`, not `custom-apparel/glitter-shirts/`. |
| 4 | Image paths are always flat under `public/images/<dir>/`. No sub-dirs within a category dir. |
| 5 | No file ever lands in the generic `custom-apparel/` image dir. Every R4 file must go to a specific named category dir (e.g., `screen-printing/`, `foil-shirts/`, `glitter-shirts/`). |
| 6 | No file is ever overwritten silently. If a target filename already exists, rename the incoming file to `top5pct-<name>-r4.jpg` and flag it. |
| 7 | Track before and after image counts for every `public/images/<dir>` touched. Record before-counts before any moves begin, update after each batch completes. |

## Section 2: Page Slot Structure

Every category page follows this layout, top to bottom. Slots are filled in this order.

| Slot | Component | Label | Notes |
|---|---|---|---|
| 1 | `x-sections.hero-banner` (or equivalent) | Banner | Always first. Always same-category image. |
| 2-5 | `x-ui.carousel-rotating-images` | Carousel | Target: 4 images, all same-category. Can expand beyond 4 only after all other non-cross-sell slots are filled. |
| 6+ | `x-sections.card-image-with-text` | Content cards | One image per card. Same-category. Alternate imagePosition left and right. |
| A | `x-sections.card-detailed-info` | Detailed info | One or two images (image1, image2). Same-category. |
| L | `x-ui.card-banner-slide-in direction="left"` | Slide-L | Same-category or cross-sell. If cross-sell, image must be R1-R4. |
| R | `x-ui.card-banner-slide-in direction="right"` | Slide-R | Always a cross-sell. Always R1-R4. Never Initial-round. |

## Section 3: Placement Rules

### 3a — Banner

- One image, always same-category as the page.
- Must be R1-R4. Leave Initial-round images in place if no R1-R4 exists yet.
- Never a cross-sell image.

### 3b — Carousel

- Target: exactly 4 images, all from this page's own category, all R1-R4.
- If fewer than 4 same-category R1-R4 images exist: fill what you can, leave the rest for a later round.
- Carousel may expand beyond 4 only after every content card, slide-L, and slide-R on the page holds a proper R1-R4 image.
- When reviewing: prioritize getting 4 proper same-category R1-R4 carousel slots filled before adding images to other slots.

### 3c — Content cards

- Fill with same-category images, round order: R1 first, R2 next, R3 next, R4 last.
- If not enough images exist to fill all cards, leave remaining cards with their current image and flag them for a future round.
- Do not swap in a worse image to fill a slot.

### 3d — Slide-R (always a cross-sell)

- Always shows an image from a different category.
- Image must physically exist in `public/images/<that-category>/` and be R1-R4.
- Linked category should be related (a complementary product type).
- Never use an Initial-round image here.

### 3e — Slide-L (may be a cross-sell)

- Can show a same-category or cross-sell image.
- If cross-sell: image must be R1-R4, same rules as slide-R.
- Prefer same-category R1-R4 before using a cross-sell.

### 3f — Cross-sell general rule

- All cross-sell images (slide-L or slide-R) must reference a file that physically exists in `public/images/<category>/`.
- Never use a cross-sell image from `custom-apparel/` or any generic catch-all dir.
- All cross-sell images must be R1-R4.
