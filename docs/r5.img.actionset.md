## Priority Guide

| Code | Meaning | Action |
|---|---|---|
| **P0** | Slot holds an Initial image (pre-migration, oldest) | Replace with new photo — highest urgency |
| **P1** | Slot holds a small/old image (<200k) mislabeled as R1/R2/R3 | Replace with new photo — same urgency as P0 |
| **Dup** | Same filename already used in an earlier slot on this page | Swap for a different image — separate from P0/P1 |
| **Fill** | Unplaced unique file, R1 or better, not small | Safe to add to carousel — no new photo needed |
| **Available** | Unplaced file that is Initial or small/old | Keep in dir for future reference — do not add to active display |

> **R1 through R5 are all acceptable.** Only Initial and small/old (<200k) mislabeled slots require replacement.
> **Dup is tracked separately from P0/P1.** A duplicated slot appears only in the Dup section — its Round column tells you if it is also old/small.
> **Available files stay in their directory.** Do not delete them — they may be reused later. They must not appear in active carousel slots.
> **Cross-sell slots** (image borrowed from another category dir) are included and flagged.
