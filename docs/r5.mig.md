## Section 1: File Migration Rules

| # | Rule |
|---|---|
| 1 | Never remove any image file. Only move or copy. Even outdated files stay on disk. |
| 2 | Apply `top5pct-` prefix to every incoming R5 filename on move. Spaces become hyphens. Uppercase filenames are lowercased. |
| 3 | Image dir name = last URL segment only. Flat under `public/images/<dir>/`. No sub-dirs within a category dir. |
| 4 | No file ever lands in the generic `custom-apparel/` image dir. Every R5 file must go to a specific named category dir. |
| 5 | No file is ever overwritten silently. If a target filename already exists, rename the incoming file to `top5pct-<name>-r5.jpg` and flag it in this doc. |
| 6 | Track before and after image counts for every `public/images/<dir>` touched. Before-counts recorded below. Update after each batch completes. |

## Section 2: Page Slot Structure

| Slot | Component | Label | Notes |
|---|---|---|---|
| 1 | `x-sections.hero-banner` or `x-sections.category-hero` | Banner | Always first. Always same-category image. |
| 2-5+ | `x-ui.carousel-rotating-images` | Carousel | Target: 4 images. Can expand only after all other non-cross-sell slots are filled. |
| 6+ | `x-sections.card-image-with-text` | Content cards | One image per card. Same-category. Alternate left and right. |
| A | `x-sections.card-detailed-info` or `x-sections.card-2image-with-text` | Detailed info | One or two images. Same-category preferred. |
| L | `x-ui.card-banner-slide-in direction="left"` | Slide-L | Same-category or cross-sell. If cross-sell, must be R1-R5. |
| R | `x-ui.card-banner-slide-in direction="right"` | Slide-R | Always a cross-sell. Always R1-R5. Never initial-round. |

---

## Section 3: Placement Rules

- Banner: one image, same-category, must be R1-R5.
- Carousel: fill 4 same-category R1-R5 slots first. Expand beyond 4 only after all content card, slide-L, and slide-R slots hold proper R1-R5 images.
- Content cards: same-category, round order R1 through R5.
- Slide-R: always a different-category cross-sell. Must physically exist in the target dir.
- Slide-L: prefer same-category R1-R5 before using a cross-sell.
- Cross-sell images must exist in `public/images/<that-category>/`. Never from generic dirs.
